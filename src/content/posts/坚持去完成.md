# 静态博客

## 基于Hexo静态博客

[Hexo官方文档]: https://hexo.io/zh-cn/docs/	"Hexo官方文档"

1. 下载 git、nodejs

2. 使用 npm 安装 Hexo

```
cnpm install -g hexo-cli
```

<!-- 图片缺失，暂注释 -->

使用   hexo -v   进行检验

3. 创建博客根文件夹

4. 建站

   执行下列命令，Hexo 将会在指定文件夹中新建所需要的文件。

   ```
   $ hexo init <folder>
   $ cd <folder>
   $ npm install  #更新依赖
   ```

5. 添加自己的博客内容

   source文件夹posts下写自己的博客

6. 更换主题

   themes下加入自己的主题

   修改 `_config.yml` 内的 `theme` 设定

   <!-- 图片缺失，暂注释 -->

7. 运行

   server

   ```
   $ hexo server
   ```

   启动服务器。默认情况下，访问网址为： `http://localhost:4000/`

8. 

## 一键部署GitHub Pages

<u>发现使用git和github一样，以下使用git  。。。。被误导了  鲁莽了 还是使用github吧</u>

1. 创建仓库

   仓库路径必须为  <你的 GitHub 用户名>.github.io

2. 安装 hexo-deployer-git

   以管理员身份运行，没用报错

   ```
   $ npm install hexo-deployer-git --save
   ```

   <!-- 图片缺失，暂注释 -->

3. 修改配置。

```
#注意空格
deploy:
  type: git
  repo: <repository url> #https://bitbucket.org/JohnSmith/johnsmith.bitbucket.io
  branch: [branch]
  message: [message]
```
